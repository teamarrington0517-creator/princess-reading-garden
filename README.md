# Kynlee's Magical Reading Garden 👑

A free, pink-and-purple, Kindle-friendly reading practice progressive web app. Features CVC phonics, sound blending, missing-vowel word building, collectible treasures, local progress tracking, and offline support.

## Publish on GitHub Pages
1. Sign in to GitHub and create a **public** repository named `princess-reading-garden`.
2. Upload **all four files** from this folder to the root of the repository (`index.html`, `manifest.webmanifest`, `icon.svg`, `sw.js`).
3. Open repository **Settings → Pages → Build and deployment → Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. Open the Pages link after deployment (typically `https://YOUR-USERNAME.github.io/princess-reading-garden/`).
5. On the Kindle Fire, open the link in **Silk Browser**. Use the browser's **Add to Home Screen** option if offered, or bookmark the page. Availability of install shortcuts and speech voices varies by Fire OS version.

## Notes
- Original decodable-style practice content; not affiliated with Teacher Created Resources (TCR).
- No ads, accounts, external services, or child data uploads.
- Rewards and progress are stored locally in the browser and can be cleared in the Grown-up Corner.
- Voice features depend on speech synthesis support on the device.
